# Ruletrade-AI

Ruletrade-AI は、保有・取引・損益と売買判断の記録を残す、個人用の投資台帳アプリです。

考えたことは、原文のまま受け箱に保存するか、項目を手入力して台帳に記録できます。台帳の読み書きは画面からだけでなく、Muse 連携 API からも行えます。

ライセンスは MIT です（[LICENSE](LICENSE)）。個人の記録用に作ったアプリなので、サポートはベストエフォートです。投資助言・売買推奨・注文実行をするアプリではありません。

## 試してみたい方へ

想定しているのは、自分のPCで自分専用に動かす使い方です。データは自分のPC内の SQLite ファイルにだけ保存され、作者のサーバーやデータとは一切つながりません。

一番簡単なのは Docker を使う方法です。Docker Desktop 等が入っていれば、Node.js を別途入れる必要はありません。

```bash
git clone https://github.com/RyoyaYahagi/Ruletrade-AI.git
cd Ruletrade-AI
docker compose up --build
```

ブラウザーで [http://localhost:3000](http://localhost:3000) を開きます。止めるときは `docker compose down`、記録したデータは Docker のボリュームに残ります（データごと消すときだけ `docker compose down -v`）。

Docker を使わない場合は、下の「自分の環境で起動する」（Node.js 24 が必要）を見てください。

試す前に知っておいてほしいこと:

- **外部AIのAPIキーは不要です。** 考えの記録・振り返り、売買の記録、CSV取込、JSON入出力を利用できます。
- **ログイン機能はありません。インターネットに公開しないでください。** あくまで自分のPCの localhost で使う前提です。公開すると、URLを知った人が記録をすべて見たり書き換えたりできます。
- **記録は自分のデータで置き換わります。** このリポジトリに作者の取引記録は含まれていません。まっさらな状態から始まります。
- **初回の起動・ビルドにはインターネット接続が必要です。** 依存パッケージの取得に加えて、画面のフォント（Google Fonts）をビルド時に取得します。オフライン環境では起動できません。
- **バックアップは JSON エクスポートで。** 「その他」画面から全記録を JSON で書き出せます。引っ越しや復元は JSON インポートで行えます。

## なぜ作ったか

投資では、買った理由も売った理由も、時間が経つと結果に引っ張られて曖昧になります。

Ruletrade-AI は、**その時点で持っていた情報から、なぜその判断をしたのか**と、売買の事実を、履歴の残る形で残すための台帳です。

個々の判断を訓練のように振り返るのではなく、保有全体をコア／サテライトの枠で管理し、割合が想定からずれていないかを確認できることを重視しています。

## 大事にしていること

### 事実と判断過程を残す

「儲かったから正しかった」「損をしたから間違っていた」だけで判断を評価しません。

何を根拠に考えたか、どんな前提を置いたか、何が起きたら考え直すつもりだったかを、売買の事実とあわせて残します。

### 過去を書き換えない

考えが変わったときは、以前の判断を上書きせずに新しい記録を追加します。入力の誤りなどを編集する場合も、変更前の内容は編集履歴に残ります。

新しい考えは新しい記録として追加し、**「以前はどう考えていて、なぜ今は違うのか」**を追えるようにしています。

### 枠で管理する

銘柄ごとにコア／サテライトの区分を持ち、変更履歴を残します。

コア／サテライトの割合は評価額（時価）ベースで管理し、枠が守られていればよいと考えています。サテライトの上限と警告線を決めておき、枠からずれたら気づけるようにします。

### 台帳と Muse 連携

記録の整理や読み返しの補助は、Muse 連携 API 経由で Muse 側が行います。アプリ本体は台帳の役割に絞ります。

AI支援は Muse 側に寄せ、アプリ本体は記録・判断・振り返りを保存する台帳として動作します。アプリ内に音声入力や自動整理・比較機能はありません。

「買うべきか」「売るべきか」を決めたり、注文を実行したりはしません。最終的な解釈と判断はユーザー自身が行います。

## できること

- **考えを記録する**：銘柄を選ぶか未定のまま、原文を受け箱へ保存できます。構造化記録では文章・銘柄・記録種別・要約・整理点などを入力して保存します。
- **銘柄ごとに読み返す**：購入、買い増し、売却の検討、仮説の更新、メモなどを時系列で読み返せます。
- **過去を振り返る**：過去の判断を画面で読み返し、現在の考えと自分の振り返りを文章で保存できます。
- **売買の事実を残す**：数量・価格・日付などを記録し、売買履歴を確認できます。価格が不明な場合は空欄のまま保存できます。
- **CSVで売買履歴を取り込む**：「その他」から、楽天証券の日本株・米国株・投資信託、SBI証券・野村證券・マネックス証券の日本株CSVを取り込めます。取り込み前に内容や重複を確認できます。
- **保有銘柄の参考時価を見る**：参考価格、時価評価額、含み損益、通貨ごとの時価構成を確認できます。国内株式と米国株式の円換算合計を表示し、米国株式はドル表示と円表示を切り替えられます。
- **売却の実現損益を見る**：売却数量と売却直前の移動平均取得単価から計算します。手数料は差し引かず、円とドルを別々に集計します。価格などが不明な売却を含む通貨の合計は「不明」と表示します。
- **コア／サテライトの配分を確認する**：銘柄の詳細画面で区分を設定し、ポートフォリオで評価額に基づく割合と残り枠を確認できます。「その他」の「枠の設定」でサテライト上限と警告線を設定でき、警告線を超えると「今日」に表示されます。
- **振り返る時期を決める**：記録にレビュー日を設定できます。期限が来た記録は、アプリを開いたときに表示されます。
- **Museから読み書きする**：連携APIで台帳の読み取りと、判断・振り返りの確定保存、売買への判断紐付けができます。仕様は [docs/integration-api-v1.md](docs/integration-api-v1.md) を参照してください。
- **JSONでエクスポートする**：「その他」画面の「JSONをエクスポート」から、銘柄・判断・売買履歴・振り返り・受け箱をダウンロードできます。過去に保存された文字起こしや整理結果、記録同士の関連も保持します。
- **JSONから記録を復元する**：「その他」の「JSONをインポート」から、エクスポートした記録を取り込めます。既存の記録は上書きせず、同じ内容は追加しません。同じ識別子で内容が異なる場合は取り込みを中止します。枠の設定は、バックアップに含まれていればその値で復元します。

## 基本的な使い方

1. 「記録」で今考えていることを書き、必要なら銘柄を選んで「受け箱に保存」を押します。銘柄が未定でも保存でき、AIは呼び出しません。
2. 保存した原文は「今日」の受け箱で見返せます。銘柄ごとの台帳に記録するときは、項目を手入力して保存します。
3. 銘柄の詳細画面のタブで、過去の判断・売買履歴・振り返りを読み返します。
4. 振り返る時期が来た記録や、理由が残っていない売買は「今日」画面に表示されます。考えが変わったときは新しい記録を追加するか、「過去と比べる」から自分の振り返りを残します。

入力した原文と過去に保存された文字起こし・整理結果は区別して保持します。新しい考えは以前の記録を上書きせず、別のタイムラインイベントとして追加されます。

ポートフォリオの保有数量と参考取得額は売買履歴から計算します。株式の参考価格には Yahoo Finance の非公式なデータ取得手段を利用します。投資信託は銘柄の詳細画面でISINと投信協会コードを設定すると、投資信託協会の基準価額で評価できます。対応する米ドルMMFなどは固定の単価で評価します。これらは外部の参考価格であり、保有履歴の正本は売買記録です。

円換算では取得額と時価評価額に同じ現在の為替レートを使うため、含み損益に為替の損益は含みません。レートを取得できないときは米国株式を含む円換算合計を表示せず、米国株式はドルで表示します。

コア／サテライトの割合は米ドル建てを円に換算し、評価額の合計から計算します。この配分計算では価格を取得できない銘柄を取得金額で代用し、未分類の銘柄はサテライト側に数えます。コアの登録がない場合は残り枠を表示しません。

## AIの利用範囲

アプリ内から外部AIサービスは呼び出しません。AI支援はMuse側で行います。アプリは入力された文章や Muse 連携 API から受け取った確定内容を保存します。売買判断や注文は行いません。APIの仕様は [docs/integration-api-v1.md](docs/integration-api-v1.md) を参照してください。

## 自分の環境で起動する

Node.js 24とnpmが必要です。外部AIのAPIキーは不要です。

```bash
git clone https://github.com/RyoyaYahagi/Ruletrade-AI.git
cd Ruletrade-AI
npm install
cp .env.example .env.local
```

作成した `.env.local` に設定します。

| 設定名                    | 内容                                                                                                                                                       |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RULETRADE_DATABASE_PATH` | 記録を保存するSQLiteデータベースの場所。初期値は `.data/ruletrade-mvp.sqlite` です。                                                                       |
| `RULETRADE_READ_TOKEN`    | Muse 連携 API の読み取り用トークン。未設定なら読み取り API は無効です。                                                                                    |
| `RULETRADE_WRITE_TOKEN`   | Muse 連携 API の書き込み用トークン。読み取り用とは異なる値を設定します。判断・振り返りの確定保存と、売買への判断紐付けを提供します。下書きは保存しません。 |

`.env.local` や記録を保存したデータベースはGitにコミットしないでください。APIキーはサーバー側で使用します。

```bash
npm run dev
```

ブラウザーで [http://localhost:3000](http://localhost:3000) を開きます。
