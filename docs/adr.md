# Architecture Decision Records

Ruletrade-AI uses ADRs to record important engineering decisions.

## When to write an ADR

Write an ADR for decisions involving:

- database architecture
- RLS
- auth/session design
- AI provider or prompt architecture
- RAG architecture
- privacy deletion
- billing
- admin access
- service role boundaries
- production operations

## Status

- proposed
- accepted
- rejected
- deprecated
- superseded

## Rule

Do not delete old ADRs. Supersede them with a new ADR.
