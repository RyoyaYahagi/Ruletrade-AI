# AIのブランチ運用

実装を始める前に現在のブランチと作業中の変更を確認する。機能追加には `feature/<内容を表す短い英語名>` のブランチを作成する。今回の例は `feature/stock-decision-capture`。

同じ機能の続きを実装するときは、その機能の既存ブランチを使う。別の機能に着手するときは新しいブランチを作る。ユーザーがブランチ名や起点を指定した場合は指定を優先する。

未コミット変更がある場合は、既存の変更を保持し、今回追加した変更を区別して報告する。コミットする場合は今回の変更だけを対象とする。既存変更の破棄や、別の作業ブランチへの混入が必要な操作は避ける。

検証結果とブランチ名を完了報告に含める。コミット、リモートへの送信、プルリクエスト作成、マージはユーザーの依頼範囲に従う。
