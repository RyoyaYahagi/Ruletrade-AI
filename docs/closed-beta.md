# Closed Beta

Ruletrade-AI uses a closed beta before public launch.

## Goals

- Validate rule creation workflow
- Validate AI Review safety
- Validate RAG usefulness
- Validate privacy settings UX
- Collect user feedback
- Detect operational issues early

## Access control

Closed beta access is controlled by:

- **Beta cohorts**: user groups per phase
- **Invite codes**: single-use or limited-use hashed codes
- **Beta access grants**: per-user permission records
- **Beta feature flags**: cohort-level feature toggles
- **Stop switches**: emergency disable controls

## Important

Closed beta users must understand that Ruletrade-AI does not provide investment advice, buy/sell recommendations, asset management, brokerage, or order execution.

## Phases

1. **Internal Alpha** — owner/admin/developer only
2. **Private Beta** — 5–30 invited users
3. **Expanded Beta** — 30–50 users with documents/watchlist
4. **Release Candidate** — 30–50 users, final validation
5. **Public** — open access
