# Engineering Standards

Ruletrade-AI engineering standards focus on safety, privacy, and operability.

## Required reviews

- DB migration
- RLS policy
- AI prompt / schema
- privacy deletion
- billing / Stripe
- service role usage
- admin permission
- dependency addition

## Pull requests

Every PR must describe:

- change area
- risk
- tests
- RLS impact
- privacy impact
- rollback plan
