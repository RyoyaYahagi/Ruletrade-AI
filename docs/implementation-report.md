# 現行実装の概要

Ruletrade-AI は SQLite を正本とする個人用の投資台帳です。画面から文章による判断記録・売買記録・振り返りを保存でき、Muse 連携 API v1 からも台帳の読み書きができます。アプリ本体は売買判断や注文を行いません。

## 主な構成

- `src/app/`：Next.js の画面と Route Handlers
- `src/features/`：記録、銘柄表示、売買、振り返り、データ入出力
- `src/lib/db/`：SQLite と Drizzle ORM
- `src/schemas/`：Zod による入力・保存データ検証
- `src/app/api/integration/v1/`：Muse 連携 API v1

## 記録と振り返り

原文は受け箱へ保存できます。銘柄の台帳に記録する場合は、文章、銘柄、記録種別、要約、整理点、任意の売買事実と振り返り日を入力して保存します。振り返りでは過去の判断を画面で確認し、現在の考えと本人の振り返りを文章で保存します。

過去に保存された文字起こし、整理結果、比較結果を保持するデータベース列、テーブル、スキーマは維持しています。これらの既存データは引き続き読み込み、編集、バックアップできます。

## 検証

実行する確認コマンドと結果は、変更ごとのレビュー記録と CI に記載します。自動テストは Vitest、画面操作は Playwright を使用します。
