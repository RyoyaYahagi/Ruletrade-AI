## Metrics

Track these KPIs:

| Metric | Target | Alert |
|--------|--------|-------|
| Daily active users | Growth | < 50 |
| Error rate | < 0.1% | > 1% |
| AI review latency | < 5s | > 10s |
| Support response | < 24h | > 48h |
| Churn rate | < 5%/mo | > 10% |
