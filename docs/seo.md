# SEO

## Sitemap

- `app/sitemap.ts` generates `/sitemap.xml`
- Only public pages are included

## Robots

- `app/robots.ts` generates `/robots.txt`
- App pages are disallowed

## Metadata

- Title and description set on landing page
- Open Graph and Twitter Card configured
- JSON-LD can be added per page

## Noindex pages

All authenticated app pages should not be indexed.

## Search Console

Verify ownership and submit sitemap after launch.
