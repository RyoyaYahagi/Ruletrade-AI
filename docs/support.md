# Support

Support infrastructure for Ruletrade-AI.

## Public pages

- `/support` — Contact / support request form
- `/help` — Help center articles

## Admin

- `/admin/support` — Support inbox (admin only)

## Tables

- `support_tickets` — User support requests
- `support_ticket_comments` — Threaded comments
- `support_help_articles` — Public help articles

## Safety

- Support staff must not display investment memo content, AI output, or document text in admin UI.
- Ticket body may contain personal content; handle with care.
- Internal comments are hidden from users via RLS.
