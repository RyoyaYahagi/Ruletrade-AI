# Getting Started

## 1. Create an account

Sign up with email and password.

## 2. Accept the usage terms

Before using the app, confirm that:

- Ruletrade-AI is not investment advice
- AI output may be wrong
- Final decisions are your responsibility

## 3. Create your first rule

Start from a ticker, company name, or investment idea.

## 4. Answer questions

The app asks questions about:

- investment thesis
- risk factors
- stop-loss condition
- position size
- review timing

## 5. Run AI Review

AI Review checks for missing fields and unclear conditions.

It does not recommend buying or selling.
