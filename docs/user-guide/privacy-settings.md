# Privacy Settings

Privacy Settings let you control stored data and AI memory.

## AI Memory

AI Memory is RAG data created from your saved rules and documents.

Deleting AI Memory removes RAG documents and chunks.

It does not delete the original rules or documents.

## AI input/output logging

「AI入出力ログを許可」をONにすると、ルール作成の改善分析のため、質問回答セットと
AI下書きの伏字済み本文が最大30日保存されます。OFFの場合は本文を保存せず、処理結果や
ハッシュなどのメタデータだけを保存します。OFFへ変更すると、既存のトレース本文も削除されます。

## Document deletion

Deleting a document removes:

- uploaded file
- extracted text
- document summary
- related RAG chunks

## Account deletion

Account deletion removes app data and storage objects before deleting the auth user.
