# UX Guidelines

## Form UX

- Label every input clearly
- Inline validation on blur
- Error messages explain what went wrong and how to fix
- Required fields marked with aria-required

## Error States

- Clear error message
- Suggested action
- Never show raw error codes to users

## Empty States

- Explain why content is empty
- Suggest next action
- Avoid "No data" alone

## Loading States

- Skeleton screens for content
- Spinners for actions
- Progress indicators for multi-step operations

## AI Safety UX

- AI output is labeled as "AI-generated"
- Include disclaimer: "This is not investment advice"
- Show confidence level when available
- Allow users to report incorrect AI output

## Financial Disclaimer

- Every AI analysis page includes disclaimer
- Disclaimer is visible, not hidden in footer
- Use clear language: "AI analysis is for reference only"

## Privacy Consent

- Clear consent before data processing
- Explain what data is collected and why
- Easy opt-out for optional features
- One-click data deletion

## Mobile UX

- Touch targets minimum 44x44px
- Horizontal scroll avoided
- Bottom navigation for primary actions
- Swipe gestures for common actions
