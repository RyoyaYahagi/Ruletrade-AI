# デザイン参考資料

このディレクトリは、旧ルール設計・評価・承認画面の試作を保存しています。現在の判断ジャーナルの仕様や実装を定義する資料ではありません。

## 参考にする部分

- 暖かみのある背景色、カード、控えめな境界線。
- 見出し・本文・補足説明の視覚的な強弱。
- 入力内容とAIが整理した内容を区別する情報の配置。
- `Calm` 版の余白と情報密度。

`Ruletrade Rule Session.html` は `Dense` 版と `Calm` 版を比較する入口です。共通の配色・部品は `styles.css` と `components.jsx`、余白を広げる調整は `styles-calm.css` にあります。

## 現在の画面との関係

現在のアプリは、このディレクトリのCSSや部品を読み込んでいません。画面は `src/app/` と `src/features/`、共通スタイルは `src/app/globals.css` に実装されています。試作を直接参考にしたかどうかは、コードの類似だけでは判断できません。

新しい画面を作る際は、試作の配色・余白・情報整理を参考にし、機能や文言は `../AGENTS.md` の現在の製品方針と実装に合わせてください。旧試作のルール承認、完成度スコア、複数AIによる評価、投資条件の提案は現在の機能として扱わないでください。
